# Speed Calc Decorator

[English](Home) · [Dansk](Home-da) · **Bahasa Malaysia**

Sebuah decorator Python yang mengukur berapa saat sesebuah fungsi mengambil masa untuk dijalankan. Ia ialah penyelesaian bagi latihan kuliah dalam *100 Days of Code: The Complete Python Pro Bootcamp* di Udemy. Wiki ini menerangkan apa yang diajar oleh setiap langkah kuliah. [README](https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/054-speed-calc-decorator) ialah versi ringkasnya.

Output yang dijangka bagi program yang siap mempunyai bentuk berikut (nombornya berbeza pada setiap mesin):

```text
1695050908.1985211
fast_function run speed: 0.33974480628967285s
slow_function run speed: 2.9590742588043213s
```
